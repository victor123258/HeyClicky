# Security notes

This is an experimental local desktop agent, not a sandbox. Keep desktop approvals enabled. Never provide secrets or permit commands you do not understand. Arbitrary approved PowerShell has your Windows user's permissions and can bypass all application-level boundaries. Prompt-injection defenses are best effort; screenshots, files and websites can contain adversarial instructions.

Main-process IPC is limited to the local fallback panel and notch workspace, and their main frames. The notch has an explicit action allowlist; the overlay has no command bridge. Expanded-notch approvals expose complete arguments, default focus to Deny, and use the same main-process ID/timeout validation as the fallback panel. Renderers have Node integration disabled, context isolation and sandboxing enabled, no generic IPC bridge, and a restrictive CSP. They render model text with textContent, not HTML. The model cannot select an arbitrary network API endpoint. No credentials belong in Git, logs, test fixtures or renderer storage.

The key is stored through Electron safeStorage (Windows DPAPI). Failure to encrypt does not fall back to plaintext. Approval is one action only, bound to a random ID, and expires on cancel or timeout. Read-only data access can expose secrets and always requires approval. All commands require approval regardless of the desktop approval preference.

Report security problems privately to the repository owner through GitHub's security reporting facility if enabled; otherwise ask the owner for a private contact without posting exploit details or credentials publicly. Review SECURITY.md, README.md and the Windows checklist before distributing this unsigned application.

Desktop tasks are serialized, not parallel. Histories are text-only and isolated per task; no task queue is persisted to disk. The voice-key helper polls only configured shortcut combinations. With Windows input, partial speech is local. Edge input may send audio to Microsoft as soon as recognition starts, including partial or cancelled speech; it does not create an AI request before release. Focusable text UI exists only in the deliberately expanded notch; hover peek stays non-activating.


## Optional Edge speech boundary

The opt-in helper uses actual Microsoft Edge on `http://127.0.0.1:21843`, bound only to IPv4 loopback. The bridge checks exact Host/Origin, does not enable CORS, denies framing, uses a restrictive CSP/no-store, and requires a random per-run bearer capability for events and the command stream. The launch fragment is moved to session storage and cleared from the URL. This capability controls voice recognition only; no AI key, screenshot, task content or generic desktop IPC is exposed to the helper. An untrusted local process running as your user is outside this boundary and could inspect browser processes/storage.

A persistent, dedicated Edge profile stores site permissions/browser data, separate from normal browsing. Permission cannot be forced permanently. A visible successful recognition test plus explicit disclosure checkbox gates automatic minimized-launch consent. No permission bypass, headless mode or microphone-indicator suppression is used. Recognition can send audio to Microsoft, even if the user later cancels; Microsoft's service terms/retention are independent of OpenRouter. Browser caches are outside the app's in-memory audio/transcript guarantee.

Stop invalidates the active provider callbacks, sends recognition abort and expects a stopped acknowledgement. An unresponsive helper is asked to close after two seconds. Window operations match only msedge processes with the exact dedicated `--user-data-dir` argument, not normal Edge windows. Closing is best effort; if blocked, manually close the dedicated helper. Quit requests closure; Delete local data also removes its profile with bounded retries and reports locked-profile failures. Neither retracts remote audio. Fallback is permitted only before release and before any delivered dictation, with a repeat notice; stale provider events cannot submit a second request.
