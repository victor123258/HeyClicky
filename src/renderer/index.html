Only when you ask
Screenshots are captured for a request, or when the agent explicitly rechecks. They stay in memory and go to OpenRouter and your selected model provider. Turn screen context off at any time.
◇
You hold the keys
Your API key is encrypted with Windows DPAPI. Conversation text stays in memory until you clear it or quit. No HeyClicky account or backend is involved.
✓
Permission before action
Commands, file access, web requests and opening links always ask. Clicking and typing ask by default. Denying an action stops the task. Use the stop hotkey to interrupt.
